# Generalized Cylinders, Predefined Surfaces, Phyllotaxis & Animation (BP.3 / v0.3)

Status: **proposed (spec locked for implementation)** (Phase 3 of [`battle-plan.md`](battle-plan.md), completing `v0.3` on [`roadmap.md`](roadmap.md)).

This document specifies **BP.3 (`v0.3`)**: closed and open-contour generalized cylinders (**3A**), predefined bicubic Bézier `.s` surfaces and `~H` instantiation (**3B**), ABOP Chapters 4–6 (phyllotaxis and timed DOL-systems) plus `RubberPlant.Viewer` developmental stepping and `sequence` export (**3C**), and the shared `Ast`/`Geometry`/`Model`/`Stats` foundation and 7-PR implementation plan.

## 1. Scope, Architecture, and Pure-Core Boundary

### 1.1 Scope

| In BP.3 (`v0.3`) | Not in BP.3 (`v0.3`) |
|---|---|
| Generalized cylinders (`StartGC`/`EndGC`) with closed (`circle`) and open (`flat`, `ucup`, `vfold`) contours | `PointGC` (`EndGC StartGC` provides one spelling per meaning) |

| Predefined `.s` bicubic Bézier patches (`include Name = "path.s";` + `~H`) with pinched-corner & seam normals | Custom free-form `.s` authoring by agents/LLMs (`.s` is an asset library) |
| ABOP Ch 4 phyllotaxis & Ch 6 timed DOL-systems (`at` productions, `settings { time = <expr>; }`) | ABOP Ch 7–8 map L-systems & fractals (`v0.4`) or `lpfg` scripting (`v1.0`) |
| Deterministic `fdlibm` `exp` and `log` in `Builtins.fs` (+ exact `x ^ 0.5 -> sqrt x`) | Interactive `--watch` on `.s` subdirectories (manual `R` reloads `.s` files) |

| `RubberPlant.Viewer` interactive stepping (`Left`/`Right`/`Home`/`End`/`Space`) & headless `sequence` PNG export | Video muxing (`ffmpeg`) inside `RubberPlant.Viewer` (users/agents consume `<prefix>0000.png`…) |

### 1.2 Pure-core / edge-I/O architecture

```text
.rp file + overrides + Limits
  ──► Pipeline.compile          (Parser -> Checker)
  ──► Pipeline.loadSurfaces     (pure callback `readText: string -> Result<string, string>`;
                                 I/O lives in Cli, Viewer, and Backends.Tests/Examples.fs)

              ├── SweptMesh.buildCylinder
              └── Bezier.tessellateSurface
```

### 1.3 F# compilation-order invariant

In `src/RubberPlant.Core/RubberPlant.Core.fsproj`, F# compiles files strictly top-to-bottom. Because `BezierSurface` uses `Vec3` and `Primitive.Surface` stores a `BezierSurface`:
- **`PatchNeighbors`, `BezierPatch`, `BezierSurface`, `SurfaceInstance`, `ContourKind`, `CrossSection`, and `GeneralizedCylinder` MUST live in `src/RubberPlant.Core/Geometry.fs`** (compiled before `Bezier.fs` and `Model.fs`).
- **`src/RubberPlant.Core/Bezier.fs`** (pure `.s` file parser and Bernstein/normal evaluator) compiles immediately after `Geometry.fs` (shared by `Pipeline.loadSurfaces` in `Core` and `Mesh.fs` in `Backends`).

### 2.2 Cross-platform deterministic `exp`, `log`, and `^ 0.5`

- **`Builtins.fs` (`exp` and `log`):** Implement pure `fdlibm` `e_exp` and `e_log` using only IEEE-754 `+ - * /` and `BitConverter` bit manipulation (matching `sin`/`cos`/`tan`), yielding bit-identical results within 1 ulp on Linux, Windows, and Windows Native AOT. Exact special cases: `exp(0.0) = 1.0`, `exp(-inf) = 0.0`, `exp(+inf) = +inf`, `log(1.0) = 0.0`, `log(0.0) = -inf`, `log(x < 0.0) = NaN`, `log(+inf) = +inf`.
- **`Eval.fs` (`^ 0.5`):** Because ABOP Chapter 4 Vogel phyllotaxis writes `n^0.5` (`r = c * sqrt(n)`) and `Pow` delegates to `Math.Pow`, special-case `y = 0.5` (when `x >= 0.0`) to `sqrt x` (IEEE-754 exact everywhere), or author Ch 4 examples with `sqrt(n)`. *(Keep `evalPow` verified against existing `fig1-37b` golden digests.)*

## 3. Generalized Cylinders — Closed & Open Contours (3A)

### 3.1 `.rp` turtle modules and semantics

Add eight PascalCase turtle modules to `Checker.turtleNames` and `Turtle.turtleArity`:

| Module | Arity | Default | Semantics |
|---|---|---|---|
| `StartGC` | 0 | — | Opens an active generalized cylinder; locks current `ContourKind` and `ContourSides`; snapshots section 0. |
| `EndGC` | 0 | — | Closes the active generalized cylinder; emits `GeneralizedCylinder` if `>= 2` sections (0 or 1 section emits nothing). |
| `ContourCircle` | 0 | — | Selects closed circular contour (`Circle`, default at start of turtle run). |
| `ContourFlat` | 0 | — | Selects open flat ribbon contour (`Flat`). |
| `ContourCup` | 1 | `0.5` | Selects open parabolic U-cup contour (`UCup(depth)`). `depth` must be finite. |
| `ContourV` | 1 | `0.5` | Selects open V-fold contour (`VFold(depth)`). `depth` must be finite. |
| `ScaleContour` | 2 | `(1, 1)` | Sets multiplicative `(ScaleL, ScaleU)` aspect ratio; both finite `>= 0`. Default `(1, 1)`. |
| `ContourSides` | 1 | `MeshOptions.Sides` | Sets facet count for subsequent GCs; finite, truncated to int `>= 3` (`< 3` raises `RP0205`). |

Design rules:
1. **Explicit `StartGC`/`EndGC` only:** Plain `F` and `G` outside `StartGC`..`EndGC` continue emitting `Segment` primitives, keeping all existing Chapter 1–3 goldens identical. `PointGC` is omitted in v0.3 (`EndGC StartGC` provides one clear spelling for contour breaks).
2. **Multiplicative `ScaleContour(sL, sU)`:** `ScaleL` and `ScaleU` persist independently of `!(w)` and bare `!`. Effective cross-section diameters at any section are `(Width * ScaleL, Width * ScaleU)`, so setting `ScaleContour(1, 0.25)` once allows `!(w)` or `!` to taper stems, petioles, and leaf blades proportionally.
3. **Contour locking & depth morphing:** `ContourKind` (its variant: `Circle` / `Flat` / `UCup` / `VFold`) and `Sides` lock at `StartGC`. Calling `ContourSides` or switching to a different contour variant mid-GC emits `RP0305` (once per drawing) and is ignored. Calling `ContourCup(d)` while already in `UCup` (or `ContourV(d)` while in `VFold`) updates `depth` for subsequent sections because the strip vertex count is invariant—allowing smooth transitions from flat base → cupped blade → flat tip.
4. **Span progression & pre-tropism ring capture:** While a GC is active, `F(d)` and `G(d)` advance `P' = P + d * H`, snapshot the next `CrossSection` **before** applying tropism bend (a deliberate RubberPlant rule so the section's `H` matches the incoming span cleanly), and increment the primitive count against `MaxPrimitives` (`RP0207`). Inside `{ ... }` polygons, an active GC is suspended (`F` draws segments as usual; `G` draws segments without recording polygon vertices).
5. **Branching (`[` / `]`):**
   - `[` pushes turtle state; if a GC is active, the child branch receives a 1-section forked GC initialized with a copy of the parent's latest section (`isForked = true`).
   - If the branch draws `F`/`G`, it continues smoothly from the parent junction and auto-emits at `]` with **no warning**.
   - If the branch calls `StartGC` while `isForked = true` and only 1 section exists, it cleanly replaces the fork with a fresh explicit GC.
   - `]` pops turtle state and restores the parent's active GC builder (auto-emitting any `isForked` GC with `>= 2` sections, or warning `RP0305` and dropping an unclosed explicit `StartGC`).
6. **Unbalanced GC handling:** `EndGC` with no active GC, explicit `StartGC` when an explicit GC is already active (or `isForked` already has `>= 2` sections), or an explicit `StartGC` still open at end-of-drawing emits `RP0305` once per drawing; unclosed explicit GCs are dropped.

### 3.2 Unified swept-contour mesh builder (`src/RubberPlant.Backends/SweptMesh.fs`)

Every `ContourKind` compiles to the same representation—a list of normalized diameter-space strips `(closed: bool * (float * float)[]) list` where `x ∈ [-0.5, 0.5]` and `(x, y)` is scaled by `(sL, sU) = (k * Width * ScaleL, k * Width * ScaleU)`:
- **`Circle`:** 1 closed strip of `s` points `(0.5 * cos(360° j / s), 0.5 * sin(360° j / s))` for `j = 0 .. s - 1`.
- **`Flat`:** 1 open strip `[(+0.5, 0.0); (-0.5, 0.0)]`. Walking `+0.5 -> -0.5` moves in `-L` (screen-left to screen-right since `L = (-1, 0, 0)`), so `(-N_L) × (+T) = +N_U`—front-face triangles face the upper (adaxial) `+U` side.
- **`UCup(depth)`:** 1 open strip of **odd** vertex count `m >= 5` (`let r = max 5 (s / 2 + 1) in if r % 2 = 0 then r + 1 else r`), guaranteeing an exact midrib vertex `(0, 0)` on the spine:
  `u_j = 1.0 - 2.0 * float j / float (m - 1)` for `j = 0 .. m - 1`, `x_j = 0.5 * u_j`, `y_j = 0.5 * depth * u_j * u_j`.
- **`VFold(depth)`:** 2 open strips `[(+0.5, 0.5 * depth); (0.0, 0.0)]` and `[(0.0, 0.0); (-0.5, 0.5 * depth)]`. Duplicating the midrib vertex at `(0, 0)` yields crisp crease normals on each blade half automatically.

#### Spine frames, parallel transport & open-contour alignment
1. **Duplicate filtering & hairpin splitting:** Drop consecutive sections with coincident positions (`|P_{i+1} - P_i| = 0`). At each interior section `i`, let `d_{i-1} = normalize(P_i - P_{i-1})` and `d_i = normalize(P_{i+1} - P_i)`. If `|d_{i-1} + d_i| < 1e-6` (180° reversal), split cleanly into separate sub-sweeps rather than producing `NaN`. Otherwise the ring plane normal (bisector tangent) is `T_i = normalize(d_{i-1} + d_i)` (with `T_0 = d_0`, `T_{n-1} = d_{n-2}`).
2. **Zero-trig 5-FLOP minimal-rotation transport** (strictly `+ - * / sqrt`, bit-identical across OSes):
   Given unit vector pair `(N_L, N_U)` perpendicular to unit `T_0` and target unit `T_1`:
   - If `1.0 + T_0 · T_1 > 1e-12`:
     $$N_L' = \text{normalize}\!\left(N_L - \frac{N_L \cdot T_1}{1 + T_0 \cdot T_1}(T_0 + T_1)\right), \qquad N_U' = T_1 \times N_L'$$
   - Otherwise (180° flip singularity): negate or construct an orthonormal fallback perpendicular to `T_1`.
3. **Mode selection (automatic by contour):**
   - **`Circle`:** Initialize `(N_{L,0}, N_{U,0})` from section 0's turtle `(L_0, U_0)` transported from `H_0` onto `T_0`, then propagate `(N_{L,i}, N_{U,i})` via minimal-rotation transport along `T_{i-1} -> T_i`. Immune to phyllotactic `/(137.5)` trunk rolls.
   - **Open contours (`Flat`, `UCup`, `VFold`):** At every section `i`, transport section `i`'s own turtle `(L_i, U_i)` from `H_i` onto `T_i` (using the `1 + H_i · T_i > 1e-12` guard; on a 180° turn like `StartGC | F(1) EndGC`, fall back to the section's `(L_i, U_i)` projected via minimal perpendicular). Preserves deliberate `/(15)` leaf twists and `$` horizontal leveling across curved leaf blades.

#### Normals, pinched tips, color transitions & double-sidedness
- Compute all vertex positions and area-weighted triangle normals across the entire sub-sweep first (skipping zero-area triangles cleanly so `!(0)` pinched leaf tips produce sharp points without `NaN` normals; vertices with zero accumulated normal receive a deterministic fallback from adjacent valid normals or `N_U`).
- Emit each span's triangles into `groupOf section_i.Color`, duplicating vertices at palette boundaries cleanly so every group remains self-contained.
- Open contours emit single-sided triangles (`+U` front normal) and rely on glTF `doubleSided: true` and Viewer `!gl_FrontFacing` (matching `Polygon` in [`backends.md` §4.3](backends.md#43-polygons)).

### 3.3 `settings { width_scale = <expr>; }` and SVG rendering
- **Auto `width_scale` trap & fix:** `Mesh.widthScale` ([`Mesh.fs`](../src/RubberPlant.Backends/Mesh.fs#L74-L108)) includes `GeneralizedCylinder` effective widths and spine points in auto-fit so upgrading ABOP Ch 2 trees to `StartGC..EndGC` keeps exact diameter parity. However, on a standalone pure-`.rp` leaf of length `4` and width `1.2`, `auto` computes `k ≈ 0.00514`, shrinking a leaf blade ~780× into a thread. Adding optional `settings { width_scale = <expr>; }` (finite `> 0`, overridable by CLI `--width-scale <k|auto>`) solves world-unit organs (`width_scale = 1;`) and Ch 6 animation fixed-`k` ([`backends.md` §4.4](backends.md#44-width-scale)) with zero impact on existing goldens.
- **SVG rendering (`Svg.fs`):** Render each span of a `GeneralizedCylinder` as a line segment with width `0.5 * (w_i + w_{i+1})` (effective width), including GC points and widths in SVG auto-fit.

## 4. Predefined Bicubic Bézier Surfaces (3B)

### 4.1 `.rp` syntax, static checks & pure loading boundary

- **Prelude declaration:**
  ```ebnf
  Include = "include" ModuleName "=" StringLit ";" ;
  ```
  - `StringLit` is lexed **only** immediately after `include <Name> =`, keeping `"` untouched as a single-character `Symbol` in module mode. Must be non-empty, single-line, and NUL-free (`RP0023`). `/` separators normalize cleanly across Windows and Linux; paths resolve relative to the `.rp` file's parent directory.
  - Only prelude-allowed (before rules, `RP0113`); unique surface names (`RP0118`); name must be a valid module identifier (not reserved keyword/builtin/setting/turtle, `RP0119`); registered in the file's module set so `let L = ...;` clashes (`RP0101`) while `L(t) -> L(t+1);` and `L(t) as L(scale);` work identically to ABOP Ch 3–5.
- **Pure loader:** `Pipeline.loadSurfaces : (string -> Result<string, string>) -> Model -> Result<Model, Diagnostic list>` resolves every `IncludeDecl` via the caller-supplied file reader (`Cli` including `rubberplant check`, `Viewer`, and `Examples.fs`), returning `RP0208` at `decl.Pos` on I/O or `.s` parse failure.

### 4.2 `.s` file parser & exact canonical alignment (`src/RubberPlant.Core/Bezier.fs`)

- **`.s` format:** Parses:
  - Bounding box line (`<minX> <maxX> <minY> <maxY> <minZ> <maxZ>`), optional `PRECISION S: <s> T: <t>` (reading **both** `s` and `t`, fixing `cpfg/patches.c`'s `s`-twice typo; integers `>= 1`),
  - `CONTACT POINT: x y z`, `END POINT: x y z`, `HEADING: x y z`, `UP: x y z`, `SIZE: s` (finite `> 0`),
  - 1+ patch blocks: patch name line, optional `TOP COLOR: ... DIFFUSE: ...` / `BOTTOM COLOR: ...` (parsed and ignored in favor of turtle palette color), optional neighbor lines (`AL:`, `A:`, `AR:`, `L:`, `R:`, `BL:`, `B:`, `BR:`), and 16 control points in row-major order `i = 0..3` (along `s`/`u`) × `j = 0..3` (along `t`/`v`).
  - Unknown or non-reciprocal neighbor patch names emit `RP0307` and are ignored so third-party `lpfg` `.s` files load cleanly.
- **Canonical orientation (ABOP Fig 5.1):** Construct right-handed surface frame from `HEADING` and `UP` (`Y_s = normalize(HEADING)`, `X_s = normalize(Y_s × normalize(UP))`, `Z_s = X_s × Y_s`) and transform each control point `p` into canonical coordinates via the exact transpose:
  $$q = \frac{p - \text{CP}}{\text{SIZE}} \cdot (X_s, Y_s, Z_s)$$
  *(Unlike `cpfg/patches.c` and `lpfg/vector3d.cpp`, which accidentally apply `B_s` instead of `B_s^T` and rotate non-symmetric frames by 90°, using `B_s^T` restores exact round-trip alignment with ABOP Fig 5.1.)*

### 4.3 `~H` turtle instantiation & primitive budgeting

When the turtle encounters `Mod("~", args)`:
- Peek at the next symbol. If it is `Mod(name, margs)` and `model.Surfaces.TryFind name` returns `Some surf`, consume that symbol and emit `Surface(instance)` at `P_t` in right-handed frame `(-L_t, H_t, U_t)` without changing `P_t` or `(H_t, L_t, U_t)`.
- **Scale arguments:**
  - `0` args (`~H`): `(1, 1, 1)`
  - `1` arg (`~H(s)`): `(s, s, s)`
  - `2` args (`~H(sx, sy)`): `(sx, sy, 1)`
  - `3` args (`~H(sx, sy, sz)`): `(sx, sy, sz)`
  - `> 3` args: consumes first 3 and emits `RP0302` once per `(name, argCount)`
  - All consumed scales must be finite (`RP0205`); negative (mirrored) and zero (flattened) scales are permitted.
- **Undeclared `~`:** If `~` is at the end of the drawing or not followed by a declared surface, emit `RP0306` once per drawing and do **not** consume the following symbol (allowing unmigrated Ch 3 stand-ins like `~ [ ... ]` to render safely).
- **Primitive budget:** Each instantiated `SurfaceInstance` counts `max 1 surf.Patches.Length` toward `MaxPrimitives` (`RP0207`).

### 4.4 Patch tessellation, degenerate corners & seam normals

- **Subdivision precedence:** CLI `--surface-div <n>` (`>= 1`, overrides both `s` and `t` to `n`) > `.s` `PRECISION (s, t)` > default `(6, 6)`.
- **Control-point pre-scaling & Bernstein evaluation:** Transform canonical control points `q` by `Scale` into world space (`P_t + (sx*q_x)(-L_t) + (sy*q_y)H_t + (sz*q_z)U_t`) *before* evaluating bicubic Bernstein polynomials `B_i(u), B_j(v)` (using `+ - *` only for bit-identical cross-platform positions and exact shared boundary edges). This yields exact normals under anisotropic (`~H(sx, sy, sz)`), mirrored, and flattened (`~H(1, 1, 0)`) scales.
- **Quad triangulation:** For `a = 0 .. sDiv - 1`, `b = 0 .. tDiv - 1`, emit `(a,b), (a+1,b), (a+1,b+1)` and `(a,b), (a+1,b+1), (a,b+1)` (matching `P_u × P_v`).
- **3-tier normal solver (for pinched/degenerate edges & corners):**
  1. **Analytical:** Compute `N = P_u(u, v) × P_v(u, v)`. Accept `normalize(N)` when `|N| > 1e-12 * |P_u| * |P_v|`.
  2. **Interior nudge:** If `|N|` vanishes (e.g., pinched leaf tip where `P_u = 0` or `P_v = 0`), nudge `(u, v)` strictly inward toward `(0.5, 0.5)` by `δ = 1e-4` (fallback `1e-2`) and recompute `P_u × P_v`.
  3. **Triangle fallback:** Average incident non-degenerate triangle normals; drop zero-area triangles completely so glTF/Viewer never receive zero or `NaN` normals.
- **Order-independent reciprocal seam averaging:** After all patches in a `BezierSurface` are evaluated, across reciprocal neighbor links (`A`: `s=0 ↔ neighbor s=1`, `B`: `s=1 ↔ neighbor s=0`, `L`: `t=0 ↔ neighbor t=1`, `R`: `t=1 ↔ neighbor t=0`, and corners `AL=(0,0)↔(sDiv,tDiv)`, `AR=(0,tDiv)↔(sDiv,0)`, `BL=(sDiv,0)↔(0,tDiv)`, `BR=(sDiv,tDiv)↔(0,0)`), sum unit vertex normals across linked patches in one immutable pass and renormalize (keeping the patch's own normal if opposite normals cancel).
- **SVG (`Svg.fs`):** Render each patch as a single 16-vertex boundary `<polygon>` (4 edges × 4 steps) for compact, crack-free SVG output (e.g., 630-floret ABOP Fig 4.4 stays ~80 KB).
- **Asset policy:** Author original minimal `.s` assets under `examples/surfaces/`; never copy GPL `vlab` `.s` files.

## 5. ABOP Ch 4 (Phyllotaxis), Ch 6 (Timed L-Systems) & Viewer Stepping (3C)

### 5.1 ABOP Chapter 4 (Phyllotaxis)

Planar (Vogel sunflower head, Figs 4.1, 4.2, 4.4) and cylindrical phyllotaxis (*Carex* L-system 4.1, pineapple/spruce scales Fig 4.11) require **no** language additions beyond 3B (`include` + `~H`) and deterministic `sqrt`/`^ 0.5`.

### 5.2 ABOP Chapter 6 (Timed DOL-Systems)

- **Syntax:**
  ```ebnf
  TimedProduction = ModuleName "at" Expr "->" ActualString ;
  ```
  and `settings { time = <expr>; }` (`time` finite `>= 0`). Continuous growth functions (`g(a, tau)`) use existing `as` interpretation rules, e.g., `a(tau) as F(A * exp(B * tau));`.
- **Static checks (`Checker.fs`):**
  - Mutually exclusive with discrete `->` productions and `settings { derivations = ...; }` (`RP0120`).
  - No context (`<`, `>`), `when`, `weight`, or `%` cut (`RP0024` / `RP0123`).
  - At most **one** `at` rule per module name (`RP0121`), with `β > 0` constant-evaluated (`RP0122`). Non-dividing modules (no `at` rule, e.g., internode `s` in ABOP §6.2.2 / Fig 6.4) age continuously forever: `D((s, τ), t) = (s, τ + t)`.
  - Every non-turtle module in `axiom:` and `at` successors must have **arity 1** (`RP0123`) with constant age expression (`0 <= τ <= β` in `axiom:`, guaranteeing `D(ω, 0) = ω`; `0 <= α < β` in successors, ABOP C2 guaranteeing finite termination; `RP0122`).
  - Turtle symbols and `[` / `]` pass through untimed without aging and cannot be `at` predecessors (`RP0123`).
  - Because `at` rules bind no formal parameters, successors constant-fold straight into `LString`.
- **Iterative engine (`src/RubberPlant.Core/TimedDerivation.fs`):**
  Implements ABOP axioms A1–A3 using an explicit work stack (never OS recursion, avoiding stack overflow) satisfying the semigroup property `D(D(x, t_a), t_b) = D(x, t_a + t_b)`:
  - `A1`: `D(x_1 ... x_n, t) = D(x_1, t) ... D(x_n, t)`
  - `A2`: `D((a, τ), t) = (a, τ + t)` when `τ + t <= β` (or `a` has no `at` rule)
  - `A3`: `D((a, τ), t) = D(succ, t - (β - τ))` when `τ + t > β`
  Enforces `Limits.MaxModules` on output length **and** as a total A3 division budget (`RP0206`), preventing infinite/billion-division hangs such as `a at 1e-12 -> a(0);`.
- **CLI flags (`Cli` + `Viewer`):**
  - `--time <t>` (finite `>= 0`): mutually exclusive with `-n` / `--derivations` (passing both exits `2`; passing `--time` on a discrete model or `-n` on a timed model exits `1`).
  - `--surface-div <n>` (integer `>= 1`): allowed on mesh (`obj`, `gltf`, `glb`) and viewer commands; rejected (`exit 2`) on `svg`, `derive`, `check`, `stats`.

### 5.3 `RubberPlant.Viewer` developmental stepping & `sequence`

- **Model caching:** `LoadedViewerModel` retains the compiled `Model` (with loaded `Surfaces`) alongside current `(Steps, Time)` so scrubbing and `sequence` export re-run only `Derivation` / `TimedDerivation` -> `interpret` -> `Turtle` -> `Mesh.build` -> `Scene` without disk I/O or re-parsing.
- **Stable `ReferenceFrame` (`Scene.fs`):**
  ```fsharp
  type ReferenceFrame =
      { Center: Vec3
        Extent: Vec3
        Bounds: Camera.Bounds
        WidthScale: float }
  ```
  `Scene.fromMeshWithFrame (frame: ReferenceFrame) (mesh: Mesh)` centers vertices against `frame.Center` and preserves `frame.Center`, `frame.Extent`, and `frame.Bounds` **even when `mesh.Groups.IsEmpty`** (fixing empty early steps such as `step = 0` of Capsella from jumping the camera/grid to `(0, 0, 0)`).
- **Interactive `view` stepping (`Interaction.fs`, `Program.fs`):**
  - `Left` / `[` and `Right` / `]` step backward/forward (`n ± 1` for discrete, `t ± dt` for timed with default `dt = max 0.05 (target / 60.0)`; `Shift` scales step by `5×` discrete / `0.2×` timed).
  - `Home` / `0` jumps to `0`; `End` jumps to target (`model.Settings.Derivations` or `Time`).
  - `Space` toggles play/pause.
  - Window title displays current stage: `RubberPlant — <file> [step k/n]` or `RubberPlant — <file> [t = 1.25]`.
  - Add `WaitEventsTimeout(seconds: float)` to `GlContext.fs` and `Renderer.IInteractiveRenderer` (keeping `Program.fs` GLFW-free per [`viewer.md` §2.4](viewer.md#24-backend-isolation-boundary-future-gpu-backend-portability)): `WaitEvents()` when paused (0% CPU), `WaitEventsTimeout` when playing.
  - `--watch` continues watching the `.rp` file; manual `R` reloads both the `.rp` and all included `.s` files.
- **Headless `sequence` command (`Protocol.fs`, `Program.fs`):**
  ```text
  rubberplant-viewer sequence <file.rp> -o <prefix> --from <a0> --to <a1>
      [--step <da> | --frames <k>] [--mode snapshot|contact-sheet|silhouette] [options]
  ```
  - Writes `<prefix>0000.png`, `<prefix>0001.png`, … atomically.
  - Discrete models accept integer `--step >= 1` (default `1`) and reject `--frames` (`exit 2`).
  - Timed models require exactly one of `--step <da>` (`> 0`) or `--frames <k>` (integer `>= 2`); passing both or neither exits `2`.
  - Reject `--stats` on `sequence` (`exit 2`).
  - **Two-pass O(1)-memory `ReferenceFrame`:** Pass 1 runs each frame `i` through `Turtle` / `Mesh.build`, accumulating the union world AABB and a fixed `WidthScale` without retaining meshes; Pass 2 re-evaluates each frame with `Scene.fromMeshWithFrame`, renders, and writes `<prefix>%04d.png`.
- **`batch` protocol additions:** `step <n>`, `time <t>`, and `sequence ...` (preserving `exit <code>` framing and transactional error recovery).
